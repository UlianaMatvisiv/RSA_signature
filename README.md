## Документація системи цифрового підпису зображень

### Короткий зміст

Це документація для стеганографічної системи цифрового підпису зображень. Система вбудовує підписи RSA у файли зображень, використовуючи стеганографію найменшого значущого біта (LSB), забезпечуючи перевірку цілісності зображень зі збереженням їх візуального вигляду. Реалізація має криптографічний захист, антикриміналістичні компоненти та практичний користувацький інтерфейс.
##  Призначення

Система цифрового підпису зображень надає надійний метод для:
- Цифрового підпису зображень для підтвердження автентичності
- перевірки цілісності зображень
- Виявлення несанкціонованих модифікацій зображень
- створення цифрових зображень, що не піддаються підробці.застосування

## Архітектура та підхід

Проєкт складається з чотирьох модулів:

 -   `main.py` — точка входу CLI (парсинг аргументів та виклик ключових функцій `sign` і `verify`).
 -  `rsa_keygen.py` - генерує пару 4096-бітних ключів RSA
    
 -   `stego.py` — стеганографічні алгоритми LSB:
    
    -   `generate_pixel_sequence` — генерує псевдовипадкову послідовність пікселів;
        
    -   `create_clean_image` — очищає LSB для підпису;
        
    -   `embed_signature` / `extract_signature` — вбудовування й екстракція бітів підпису;
        
    -   `get_clean_image_for_verification` — відтворює первісний стан пікселів;
        
    -   `add_fake_signature_markers` — додає псевдосигнатури для ускладнення аналізу файлу.
        
 -   `crypto.py` — XOR:
    
    -   `xor_crypt` — шифрування/дешифрування підпису;
        
 -   `io_utils.py` — високорівневі функції:
    
    -   `sign_image` — підпис і стеганографія в одному виклику;
        
    -   `verify_image` — верифікація вбудованого підпису.
        
### Генерація 4096‑бітних ключів RSA

- Створюється 4096-бітний приватний ключ RSA зі стандартним відкритим    ключем (65537). Отримується відповідний відкритий ключ. Такий розмір    ключа забезпечує дуже високий рівень безпеки.
- Створюється спеціальний    каталог ключів, якщо його не існує
-  Зберігається приватний ключ у    форматі PKCS#8, який є стандартним форматом для приватних ключів, а відкритий ключ у форматі SubjectPublicKeyInfo (стандарт    для відкритих ключів). Обидва ключі закодовуються у форматі PEM.

### Кроки підходу

Рішення використовує LSB-стеганографію з декількома розширеними можливостями:
- **Псевдовипадковий вибір пікселів**: Використовує детерміновану, але непередбачувану послідовність для вбудовування
- **Багатоканальне вбудовування**: Розподіляє біти підпису по R,G,B каналах
- **Змінний крок**: Використовує стрибки змінної довжини між пікселями для захисту від виявлення
- **Шифрування підпису**: XOR-шифрування даних підпису перед вбудовуванням

### Обробка зображень

Система обробляє зображення у декілька етапів:

1. **Підготовка**:
   - Перетворення в колірний простір RGB, якщо потрібно.
   - Обчислення хешу "чистого" зображення (з очищеними LSB в місцях, де буде підпис)
   
2. **Підписання**:
   - Генерація детермінованої псевдовипадкової послідовності пікселів
   - Створення RSA-підпису хешу зображення
   - Шифрування підпису за допомогою шифру XOR (отриманого з хешу зображення)
   - Вбудовування зашифрованого підпису в LSB
   
3. **Верифікація**:
   - Відновлення вихідної послідовності пікселів
   - Витяг вбудованого підпису
   - Розшифрування підпису за допомогою ключа XOR
   - Відтворення чистого стану зображення
   - Перевірка підпису за хешем чистого зображення

### Заходи протидії криміналістиці

Реалізація включає в себе декілька анти-кримінальних методів:

1. **Змінний крок**: Замість того, щоб використовувати суміжні пікселі, система використовує змінні кроки між пікселями, що ускладнює виявлення шаблону.

2. **Випадкові стрибки**: 10% ймовірність переходу на 10-50 пікселів вперед у послідовності.

3. **Шифрування підпису**: XOR-шифрування підпису перед вбудовуванням.

4. **Фальшиві маркери підпису**: Додає в кінець файлу шаблони, що вводять в оману, схожі на підписи:
   - Випадкова кількість (2-5) підроблених підписів
   - Випадкові розміри (256-512 байт)
   - Фальшиві заголовки (`SIG\x00RSA\x00`)
   - Маркери кінця фальшивого підпису

5. **Детермінізм на основі seed** : Всі випадкові значення отримуються з розмірів зображення та значень, наданих користувачем, що усуває необхідність зберігати параметри.

### Ключові компоненти
* Генерація послідовності пікселів

> def generate_pixel_sequence(image_shape, seed_modifier=None):

    
  Генерує псевдовипадкову послідовність зі змінним кроком між пікселями.

Ця функція створює детерміновану, але непередбачувану послідовність позицій пікселів на основі:

	 - Розміри зображення (висота × ширина)
	 - Додатковий модифікатор seed (для
	   різних послідовностей з одного зображення)
	 - Хешування SHA-256 для
	   генерації seed
	 - Змінний крок між послідовними пікселями
	 - Випадкові стрибки, щоб уникнути виявлення шаблону
* Вбудовування підпису

> def embed_signature(image_array, signature, seed_key):

   
   Вбудовує підпис у зображення за допомогою LSB-стеганографії

Основні можливості:

	- Шифрує підпис за допомогою XOR перед вбудовуванням
	- Підготовляє довжину підпису (4 байти) до даних
	- Розподіляє біти по каналах R,G,B
	- Модифікує лише LSB вибраних пікселів
* Компоненти захисту від підробки

> def add_fake_signature_markers(image_path):

 Додає фальшиві маркери підписів у кінець файлу, щоб заплутати аналітиків
Ця функція додає декілька шаблонів-приманок після даних зображення:
		

    - Шифрує підпис за допомогою XOR пе
    - Випадкова кількість фальшивих підписів
    - Різні розміри з переконливою структурою, схожою на підпис
    - Фальшиві заголовки та термінатори
